# دليل تشغيل ونشر وبيع تطبيق «سبيرات»

## 1. ما في الحزمة

| المجلد | المحتوى |
|---|---|
| الملفات الرئيسية (`index.html` و`js` و`css` و`icons`) | التطبيق نفسه، يشتغل في المتصفح ويتثبت كتطبيق |
| `supabase/setup.sql` | قاعدة البيانات: الجداول والصلاحيات والبحث |
| `packaging/android-ios` | مشروع أندرويد وآيفون (Capacitor) مع الأيقونات وشاشة البداية |
| `packaging/windows` | تطبيق ويندوز (Electron) يطلع منه ملف تثبيت ‎.exe |
| `packaging/ci/android-apk.yml` | بناء ملف APK للأندرويد تلقائياً على GitHub |
| `store-assets` | صور المتاجر (1080×1920) وبانر Google Play (1024×500) |
| `docs` | هذا الدليل ونصوص وصف التطبيق للمتاجر |
| `privacy.html` | سياسة الخصوصية، تطلبها كل المتاجر |

## 2. التشغيل أول مرة (15 دقيقة)

1. سجّل في [supabase.com](https://supabase.com) وأنشئ مشروعاً مجانياً. يُفضّل منطقة فرانكفورت (eu-central-1) لأنها الأقرب لليبيا.
2. **SQL Editor** ← New query ← الصق كامل `supabase/setup.sql` ← **Run**.
3. **Authentication ← Sign In / Providers ← Email**: أطفئ **Confirm email**. خدمة البريد المجانية محدودة الرسائل، فالأفضل تطفي التأكيد أو تربط بريد خاص (SMTP).
4. **Authentication ← URL Configuration**: ضع رابط موقعك في **Site URL**.
5. **Project Settings ← API**: انسخ **Project URL** والمفتاح العام (anon أو publishable) وحطهم في `config.js`.
6. ارفع الملفات على GitHub Pages أو Netlify أو Cloudflare Pages.
7. افتح الموقع وسجّل حسابك قبل أي أحد، لأن **أول حساب يصبح حساب الإدارة**.

## 3. التثبيت المباشر بدون متاجر

- **أندرويد (Chrome)**: يطلع زر «تثبيت» في الصفحة الرئيسية أو في قائمة المتصفح.
- **آيفون (Safari)**: زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **ويندوز (Edge أو Chrome)**: أيقونة التثبيت في شريط العنوان.

## 4. النشر في المتاجر

### الطريق الأسهل: PWABuilder (مجاني، من Microsoft)

افتح [pwabuilder.com](https://www.pwabuilder.com) وحط رابط موقعك. يطلعلك:

- **Android**: ملف AAB جاهز لـ Google Play، وملف APK للتجربة، ومفتاح التوقيع. احفظ المفتاح عندك، لأنه يلزمك لكل تحديث.
- **Windows**: حزمة MSIX لـ Microsoft Store.
- **iOS**: مشروع Xcode يُرفع من جهاز ماك.

### مشروع Capacitor (تحكم كامل)

```
cd packaging/android-ios
npm install
npm run android    # ينشئ مشروع Android Studio بالأيقونات
npm run ios        # على جهاز ماك فقط: ينشئ مشروع Xcode
```

بعدها افتح المشروع في Android Studio أو Xcode، ووقّع النسخة وارفعها للمتجر.

### APK تلقائي من GitHub

انقل `packaging/ci/android-apk.yml` إلى المجلد `.github/workflows/` في المستودع. بعدها كل تحديث يطلع ملف APK من **Actions ← Android APK ← Artifacts**.

### ويندوز ‎.exe

```
cd packaging/windows
node copy-web.js
npm install
npm run dist       # ملف التثبيت يطلع في dist/
```

### الحسابات المطلوبة (باسمك)

- **Google Play**: 25 دولار مرة وحدة. الحسابات الشخصية الجديدة لازم تجرب التطبيق مع 12 مختبِر لمدة 14 يوم قبل النشر العام.
- **App Store**: 99 دولار في السنة، ويلزم ماك (أو خدمة بناء سحابية).
- **Microsoft Store**: حساب مطور من Partner Center. راجع رسومه الحالية هناك.

## 5. تغيير الاسم والشكل (لو تبيعه لعميل باسمه)

- **الاسم**: المفتاح `app` في `js/i18n.js` (بثماني لغات)، و`manifest.webmanifest`، و`<title>` في `index.html`، و`appName` و`appId` في `packaging/android-ios/capacitor.config.json`.
- **الألوان**: متغيرات `--signal` (البرتقالي) و`--asphalt` (الداكن) في أول `css/styles.css`.
- **الأيقونة**: الأصل في `icons/icon.svg`. استبدل الصور في `icons/` و`packaging/android-ios/assets/` بنفس الأحجام.
- **الدولة الافتراضية**: `defaultCountry` في `config.js`.

## 6. نسخة لشركة واحدة (مثل Corssky)

لو المشتري شركة وحدة بفروعها (مش سوق محلات):

```
python3 branding/corssky/make_assets.py     # الأيقونات وشاشة البداية (لشركة ثانية: انسخ المجلد وغيّر الألوان والحرف)
python3 tools/build_company.py --name "Company" --email owner@company.ly --brand branding/corssky/png --out company
```

يطلع مجلد كامل باسم الشركة وأيقوناتها: التطبيق وقاعدة البيانات وقارئ الفواتير وبرنامج الربط والتغليف لأندرويد وآيفون وويندوز، ومعاه «دليل نسخة الشركة». فيه منظومة مبيعات وصلاحيات موظفين وإخفاء أسعار وباركود وتصوير فواتير الموردين.

## 7. البيع والتسليم

- سلّم المشتري الحزمة كاملة مع هذا الدليل. الكود كله مكتوب لك، والملكية لك، وتقدر تبيعه.
- مكونات خارجية مسموح استخدامها تجارياً: مكتبة supabase-js (رخصة MIT)، خطوط Changa وIBM Plex (رخصة OFL)، بيانات NHTSA (ملكية عامة أمريكية).
- لا يحتوي التطبيق على شعارات ماركات السيارات، فقط أسماؤها، وهذا يبعدك عن مشاكل العلامات التجارية.
- **انتبه**: مستودع GitHub الحالي عام، يعني أي أحد يقدر يشوف الكود وينسخه. لو تبي تبيعه كمنتج حصري، خلّ المستودع خاصاً وانقل الاستضافة إلى Netlify أو Cloudflare Pages، لأنهم يقبلوا المستودعات الخاصة مجاناً.

## 8. التكاليف والتشغيل

- خطة Supabase المجانية تكفي للبداية: 500 ميجا للبيانات و1 جيجا للصور. المشروع المجاني يتوقف إذا ما استخدمه أحد أسبوعاً كاملاً، ويرجع بضغطة من لوحة التحكم.
- للتشغيل التجاري الدائم يُنصح بخطة Pro المدفوعة الشهرية.
- الصور تُضغط داخل الهاتف قبل الرفع (أقصى عرض 1400 بكسل، مع نسخة مصغرة للبطاقات)، فالمساحة تكفي آلاف القطع.
